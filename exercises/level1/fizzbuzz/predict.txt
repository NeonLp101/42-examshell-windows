@@ question
match: text
answer: fizz
wrong: fizzbuzz => That's what the correct program prints. With this order the fizz test catches 15 first.
The tests are written in this order. What does this program print on line 15?

    if (i % 3 == 0)
        write(1, "fizz", 4);
    else if (i % 5 == 0)
        write(1, "buzz", 4);
    else if (i % 15 == 0)
        write(1, "fizzbuzz", 8);
---
An else-if chain stops at the first true test: `15 % 3 == 0` is true, so "fizz" is
printed and the fizzbuzz test is never reached. The 15 test must come first.
