@@ question
answer: {NULL}
accept: { NULL }
wrong: {"\t", "\n", NULL} => Tabs and newlines are separators too, just like spaces.
    ft_split(" \t \n ")
---
The subject defines words as delimited by "spaces/tabs/new lines". This string
contains only separators, so there are no words.

@@ question
answer: {"one", "two", "three", NULL}
wrong: {"one\ttwo\nthree", NULL} => \t (tab) and \n (newline) are separators, not part of a word.
    ft_split("one\ttwo\nthree")
---
In a C string literal `\t` is one tab character and `\n` one newline character -
both separators. So there are three words.

@@ question
answer: {"a,b;c", "d", NULL}
wrong: {"a", "b", "c", "d", NULL} => Only spaces, tabs and newlines separate words. Commas and semicolons are normal characters.
    ft_split("a,b;c d")
---
Punctuation is not a separator in ft_split: "a,b;c" is one word.

How many `char *` slots must the first malloc hold?

    ft_split("a b c")
---
3 words + 1 slot for the NULL terminator = 4, i.e. `malloc(sizeof(char *) * 4)`.
