@@ intro
The same idea as bubble sort, but on a linked list: compare each node with the next
one, and if they're in the wrong order, swap their DATA.

Swapping the data (two ints) is much simpler than swapping the nodes themselves,
which would mean re-linking `next` pointers - and maybe changing the head.

The subject's twist is `cmp`: you don't decide the order yourself. `cmp(a, b)`
returns non-zero when a and b are in the right order, 0 otherwise - so the same
function can sort ascending, descending, or any way the caller wants.

This version goes back to the head after every swap, and stops when it walks the
whole list without swapping anything.

list.h is provided by the exam (you include it, but don't turn it in):

    typedef struct s_list t_list;

    struct s_list
    {
        int     data;
        t_list  *next;
    };

Read the subject's contract carefully: cmp returns NON-ZERO when a and b are
already in the right order. So we swap when it returns 0.

With `ascending(a, b) { return (a <= b); }`:

    cmp(1, 5) => 1     in order, keep
    cmp(5, 1) => 0     wrong order, swap
    cmp(3, 3) => 1     equal counts as in order, keep

`int (*cmp)(int, int)` is a pointer to a function taking two ints and returning an
int. You call it like a normal function: `cmp(x, y)` (or `(*cmp)(x, y)`).

hint: A swap can break the order with the pair BEFORE cur. Where do you start checking again?
After a swap, the smaller value moved one step left - it might need to move further
left, and only a new walk from the start can do that. So we go back to the head.

    [3, 2, 1]    swap 3,2  =>  [2, 3, 1]    restart
                 2,3 ok, swap 3,1  =>  [2, 1, 3]    restart
                 swap 2,1  =>  [1, 2, 3]    restart
                 1,2 ok, 2,3 ok, end of list  =>  sorted

It's not the fastest bubble sort, but it's short and obviously correct: the loop
can only reach the end of the list when no pair is out of order.

The function returns a `t_list *` because a solution that re-links nodes could end

@@ outro
Bubble sort on a list:

    cur = lst
    while (cur && cur->next)
        if (!cmp(cur->data, cur->next->data))
            swap the two data, then cur = lst
        else
            cur = cur->next
    return lst

Remember:
- cmp returns non-zero for "right order" => swap when it returns 0
- swap the data (ints), not the nodes => the head never changes
- `cur && cur->next`, in that order, protects against NULL
- don't turn in list.h - the grader uses its own, you just #include "list.h"
