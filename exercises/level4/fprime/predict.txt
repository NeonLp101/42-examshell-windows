@@ question
match: exact
args: ["42"]
answer: 2*3*7$
    $> ./fprime 42 | cat -e
---
Trial division: 2 divides 42 (n = 21), 2 doesn't divide 21 so try 3 (n = 7),
then 4, 5, 6 don't divide 7, and 7 does (n = 1). The `*` only goes BETWEEN
factors, so there's no star before the `$`.

@@ question

answer: $
    $> ./fprime | cat -e
---
No parameter => only the newline. `cat -e` shows it as a single `$`.
Forgetting to print "\n" in this case is one of the most common FAILUREs.

itself. A prime prints as itself, no star.

again: 16 => 8 => 4 => 2 => 1. Four times.

@@ question
match: exact
args: ["60"]
answer: 2*2*3*5$
wrong: 2*3*5$ => 60 = 2*2*3*5: the 2 divides twice (60 => 30 => 15).
    $> ./fprime 60 | cat -e
---
60 => 30 (2) => 15 (2 again) => 5 (3) => 1 (5). Factors are printed in ascending
order automatically, because the loop tries factors from small to big.
