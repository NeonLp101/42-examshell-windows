@@ question
answer: -4
wrong: 4 => In C the remainder takes the sign of the left operand: -1234 % 10 is -4.
What is the value of this C expression?

    -1234 % 10
---
In C (since C99) `%` keeps the sign of the dividend: -1234 % 10 == -4. That's why
ft_itoa stores the '-' first and then makes n positive - otherwise `n % 10 + '0'`
would produce characters BELOW '0'.

@@ question
answer: 55
accept: '7'
What int value does this expression have?

    '0' + 7
---
'0' has the ASCII code 48, so '0' + 7 = 55, which is the code of the character
'7'. That's how a digit (0 to 9) becomes a character.

@@ question
answer: 123
wrong: 123.4 => Integer division drops the decimals: 1234 / 10 == 123.
What is the value of this C expression?

    1234 / 10
---
Dividing two ints truncates: the result is 123, not 123.4. That's exactly what
removes the last digit in `n /= 10`.
