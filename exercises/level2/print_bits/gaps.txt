@@ intro
A byte has 8 bits, numbered 7 (left, most significant) to 0 (right). To print them in
order, look at bit 7 first, then 6, ... then 0.

Reading bit i: shift the byte right by i so that bit lands in position 0, then keep only
that bit with `& 1`.

    42 = 00101010      (42 >> 3) = 00000101      & 1  =>  1

@@ file print_bits.c
#include <unistd.h>

void	print_bits(unsigned char octet)
{
	int		i;
	char	c;

	i = {{1}};
	while (i >= 0)
	{
		c = {{2}};
		write(1, &c, 1);
		i--;
	}
}

@@ gap 1
answer: 7
wrong: 8 => A byte has bits 7 to 0: starting at 8 prints 9 characters.
wrong: 0 => The loop counts DOWN (i--): starting at 0 prints one bit only. Start with the leftmost bit.
hint: The leftmost bit of a byte is number...
The bits of a byte are numbered 7 (leftmost) down to 0. We print from left to right, so
we start at 7 and count down to 0: 8 characters.

hint: Shift bit i down to position 0, keep only that bit, turn 0/1 into '0'/'1'.
Three operations:

    octet >> i       bit i moves to position 0
    ... & 1          mask: keep only that lowest bit (0 or 1)
    '0' + ...        number 0/1 => character '0'/'1'

(`(octet & (1 << i)) ? '1' : '0'` does the same by building a mask for bit i instead.)

@@ outro
Bit toolbox:
- `n >> i` shifts right (bit i goes to position 0)
- `n & 1` keeps only the lowest bit
- `1 << i` is a number with only bit i set
- print from bit 7 down to 0 for normal reading order
- print_bits prints NO newline
