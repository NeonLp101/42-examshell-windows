@@ intro
strcspn(s, reject) returns how many characters at the START of s contain none of the
characters of reject - i.e. the index of the first character of s that IS in reject
(or the length of s if there is none).

    strcspn("hello", "l")    = 2      ('l' is at index 2)
    strcspn("hello", "xyz")  = 5      (no match: the whole length)

Two nested loops: for each character of s, look for it in reject.

@@ gap 1
answer: reject[j]
accept: reject[j] != '\0'
accept: reject[j] != 0
wrong: s[j] => j walks through reject, not through s.
wrong: reject => reject is the pointer, it never changes: test the character reject[j].
hint: Walk through every character of reject.
The inner loop checks each character of reject against the current character s[i].

@@ gap 2
answer: s[i] == reject[j]
accept: reject[j] == s[i]
wrong: s[i] != reject[j] => That stops at the first character that is DIFFERENT - almost always right away.
hint: Is the current character of s one of the rejected characters?
As soon as s[i] matches any character of reject, we found the answer.

@@ gap 3
answer: i
wrong: j => j is a position in reject. The answer is the position in s: i.
wrong: i + 1 => i characters come before s[i] (indexes 0 to i - 1): return i.
hint: How many characters of s came before this one?
Characters 0 to i - 1 were all accepted, s[i] is rejected: the length of the accepted
start is exactly i.

@@ gap 4
answer: i
wrong: 0 => If no rejected character was found, the WHOLE string counts: return its length, i.
hint: No character of s is in reject. What is i now?
The outer loop ended on the '\0' of s, so i is the length of s: every character was
accepted.

@@ outro
Remember:
- strcspn = length of the start of s made of characters NOT in reject
- strspn (its twin) = length of the start made of characters that ARE in accept
- size_t is the unsigned type used for lengths and sizes
