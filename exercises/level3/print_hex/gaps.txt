@@ intro
Convert the argument to an int (digits only), then print it in base 16.

Printing in a base is the same recursion as put_nbr: first print everything except the
last digit (n / 16), then the last digit (n % 16). The digit character comes from the
string "0123456789abcdef": its character number 11 is 'b'.

@@ file print_hex.c
#include <unistd.h>

void	put_hex(int n)
{
	if ({{1}})
		put_hex(n / 16);
	write(1, {{2}}, 1);
}

int	main(int argc, char **argv)
{
	int		n;
	char	*s;

	if (argc == 2)
	{
		n = 0;
		s = argv[1];
		while (*s >= '0' && *s <= '9')
			n = {{3}};
		put_hex(n);
	}
	write(1, "\n", 1);
	return (0);
}

@@ gap 1
answer: n >= 16
accept: n > 15
accept: 16 <= n
accept: n / 16
accept: n / 16 > 0
wrong: n > 16 => 16 itself needs two digits ("10"): with > it would print only "0".
wrong: n >= 10 => That's the base-10 test. In base 16, one digit goes up to 15.
hint: Does n have more than one hexadecimal digit?
Numbers 0-15 are a single hex digit; from 16 on there are digits in front, printed first
by the recursive call.

@@ gap 2
answer: &"0123456789abcdef"[n % 16]
accept: "0123456789abcdef" + n % 16
accept: "0123456789abcdef" + (n % 16)
accept: &("0123456789abcdef"[n % 16])
wrong: "0123456789abcdef"[n % 16] => That's the character. write needs its ADDRESS: add &.
wrong: &"0123456789abcdef"[n] => Only the last digit is printed here: n % 16.
wrong: "0123456789ABCDEF" + n % 16 => The subject wants lowercase letters.
hint: Pick the digit character from a string of all hex digits, and give write its address.
A string literal is an array, so it can be indexed: `"0123456789abcdef"[11]` is 'b'.
`n % 16` is the last hex digit (0-15), which is exactly its index in that string. The
`&` gives the address write needs.

@@ gap 3
answer: n * 10 + (*s++ - '0')
accept: n * 10 + *s++ - '0'
accept: 10 * n + (*s++ - '0')
accept: (*s++ - '0') + n * 10
wrong: n * 10 + (*s - '0') => s never moves: infinite loop. Use *s++.
wrong: n * 16 + (*s++ - '0') => The ARGUMENT is written in base 10: parse it with * 10.
hint: Classic atoi step - and move s forward in the same expression.
The input is decimal: `n * 10 + digit`. `*s++` reads the character, then moves s.

@@ outro
The base-printing pattern (put_nbr, print_hex, any base):

    if (n >= base)
        put_base(n / base);
    write(1, &"0123456789abcdef"[n % base], 1);

Remember: parse in base 10, print in base 16, lowercase letters, "0" for 0.
