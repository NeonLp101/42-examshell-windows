@@ question
answer: [3, 2, 1]
wrong: [1, 2, 3] => That's ft_range. ft_rrange starts at end.
Type the array, like [1, 2, 3]:

    ft_rrange(1, 3)
---
From end (3) back to start (1).

@@ question
answer: [-3, -2, -1, 0]
    ft_rrange(0, -3)
---
From end (-3) up to start (0).

@@ question
answer: 13
wrong: 16 => Without parentheses the + 1 is added AFTER the multiplication.
What is the value of this expression (sizeof(int) is 4)?

    sizeof(int) * 3 + 1
---
`*` before `+`: 4 * 3 + 1 = 13, not 4 * (3 + 1) = 16. Classic malloc bug.
