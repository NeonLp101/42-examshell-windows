@@ intro
ft_rrange is ft_range in reverse: the array starts at END and walks toward start.

    (1, 3)   => [3, 2, 1]          (0, -3)  => [-3, -2, -1, 0]

This version uses a `step`: +1 or -1, so every value is `end + i * step`.

@@ file ft_rrange.c

@@ gap 1
answer: (len + 1)
accept: (1 + len)
wrong: len + 1 => Precedence: sizeof(int) * len + 1 is (4 * len) + 1 bytes - room for one int less. Put parentheses: (len + 1).
wrong: len => Both ends are included: len + 1 elements.
hint: Both ends are included - and watch the operator precedence.
Here len is the distance, so there are len + 1 values. The parentheses are essential:
`*` binds tighter than `+`, so without them we'd allocate 4 * len + 1 bytes - 3 bytes
short of the last int.

@@ gap 2
answer: (start > end) ? 1 : -1
accept: start > end ? 1 : -1
accept: (start <= end) ? -1 : 1
accept: start <= end ? -1 : 1
accept: (end < start) ? 1 : -1
wrong: (start > end) ? -1 : 1 => Reversed: we walk from end TOWARD start. If start is bigger, the values go up (+1).
wrong: 1 => (1, 3) must go 3, 2, 1: the step depends on the direction.
hint: From end, which direction leads to start?
We start at end and must reach start. If start is bigger, we go up (+1); otherwise down
(-1):

    (1, 3):  end = 3, start = 1 is smaller  => step -1  => 3, 2, 1

@@ gap 3
answer: i <= len
accept: i < len + 1
accept: len >= i
wrong: i < len => len is the distance: there are len + 1 values. The last one would be missing.
hint: len is the distance - how many values are there?
Values for i = 0 ... len: that's len + 1 values, matching the malloc.

@@ gap 4
answer: end + i * step
accept: end + step * i
accept: i * step + end
wrong: start + i * step => ft_rrange starts at END.
wrong: end + i => Always going up: wrong when start < end. Use the step.
hint: The i-th value, starting from end and moving by step.
end, end + step, end + 2 * step, ... until start.

@@ outro
Remember:
- ft_rrange(start, end) begins at END
- count = |end - start| + 1
- `malloc(sizeof(int) * (len + 1))`: parentheses!
- a step of +1/-1 handles both directions with one formula
