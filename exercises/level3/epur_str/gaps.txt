@@ intro
Print the words of the string separated by exactly ONE space, with nothing at the start
or the end. The loop: skip blanks, stop if the string is over, print a separator if a
word was already printed, then print the word.

    " this        time it  "   =>   "this time it"

@@ file epur_str.c
#include <unistd.h>

int	main(int argc, char **argv)
{
	char	*s;
	int		printed;

	if (argc == 2)
	{
		s = argv[1];
		printed = 0;
		while (*s)
		{
			while ({{1}})
				s++;
			if ({{2}})
				break ;
			if ({{3}})
				write(1, " ", 1);
			while (*s && *s != ' ' && *s != '\t')
				write(1, s++, 1);
			printed = 1;
		}
	}
	write(1, "\n", 1);
	return (0);
}

@@ gap 1
answer: *s == ' ' || *s == '\t'
accept: *s == '\t' || *s == ' '
wrong: *s == ' ' => Tabs are blanks too: "delimited by spaces/tabs".
wrong: *s != ' ' && *s != '\t' => That's "inside a word". Here we skip the blanks.
hint: Skip spaces and tabs.
Skip every blank before the next word - leading ones and the extra ones between words.

@@ gap 2
answer: !*s
accept: *s == '\0'
accept: *s == 0
wrong: *s => Reversed: that breaks when there IS a word coming.
hint: The blanks were skipped - but maybe they were trailing blanks.
If skipping blanks reached the '\0', there's no word left: stop BEFORE printing a
separator. Otherwise "abc   " would print "abc " with a trailing space.

@@ gap 3
answer: printed
accept: printed == 1
accept: printed != 0
wrong: !printed => Reversed: that puts a space before the FIRST word only.
wrong: 1 => That also prints a space before the first word: " this time".
hint: A space goes between words - so not before the first one.
The separator goes before every word except the first. The `printed` flag remembers
whether a word was already written.

@@ outro
The "words with one separator" loop - reused in expand_str, rostring...

    while (*s)
        skip blanks
        if end => break
        if a word was printed => separator
        print the word

Remember: no blank at the start, none at the end, exactly one between words.
